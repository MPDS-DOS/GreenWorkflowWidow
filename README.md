# GreenWorkflowWidow

Agentic science workloads for OS experiments: [ChemGraph](chemgraph/) against a self-hosted LLM ([llm/](llm/)).

| Workload | Questions | Duration |
| --- | --- | --- |
| `small` | 40 benchmark questions, small molecules, graded | ~40 min |
| `big` | 90 questions, 30 molecules up to drug size | ~2 h |
| `huge` | 270 questions, `big` with three MACE model sizes | ~6–10 h |

Setup and run: [chemgraph/](chemgraph/).
