# GreenWorkflowWidow

Agentic science workloads for OS experiments: [ChemGraph](chemgraph/) against a self-hosted LLM ([llm/](llm/)).
All questions come from the ChemGraph authors ([datasets/](datasets/)).

| Workload | Questions | Duration |
| --- | --- | --- |
| `small` | 40 benchmark questions, graded | 38 min |
| `big` | 60 questions from the paper evaluation | ~2 h |
| `huge` | 300 questions from the paper evaluation | ~12 h |

Setup and run: [chemgraph/](chemgraph/).
